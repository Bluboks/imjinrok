# Noto Sans KR browser asset

- Upstream package: `@fontsource/noto-sans-kr`
- License: SIL Open Font License 1.1 (see [OFL.txt](./OFL.txt))
- Included browser file: `NotoSansKR-Regular.woff2`
- SHA-256: `3aa0d1d63f3b5b2a33053a41a34512eac63abfb1dc2112aeda04733656a1a6d9`

The game bundles only the regular WOFF2 face for pre-game dynamic Korean text.
It is declared with `font-display: swap` so first paint can use platform
fallbacks and redraw after the local font becomes ready.
