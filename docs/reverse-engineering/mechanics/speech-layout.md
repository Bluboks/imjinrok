# `SPEECH` 대화 레이아웃

기준일: 2026-07-26

## 판정 범위

원본 스크립트의 `SPEECH` 숫자 슬롯이 초상화 사각형으로 변환되는 규칙과 대사 배치를 `정적 확정`했다.
EXE의 레코드 소비자, 고정 좌표 함수, 텍스트 배치 함수와 `hero.spr` 크기를 하나의 흐름으로 연결했고
고정 해시와 명령어 anchor를 검사하는 추출기를 만들었다.

이 판정은 제목, 목표, 버튼, 글꼴 종류·크기, HUD 전체 배치에는 적용하지 않는다.

## 데이터와 호출 흐름

| 주소 | 확인한 동작 |
| ---: | --- |
| `0x0048311e` | `WORD [SPEECH 레코드+0x80]`에서 숫자 표시 슬롯을 읽음 |
| `0x00483133` | 슬롯과 대사 payload를 `FUN_004a7b10` 호출 인수로 전달 |
| `0x004a7b10` | 선택 슬롯 초상화 갱신과 대사 텍스트 배치를 조정 |
| `0x004a8410` | signed 슬롯 0~3을 고정 초상화 사각형으로 변환 |
| `0x004a7a50` | 대사를 폭 278에 맞추고 X 188, Y 190 중심으로 그림 |

`FUN_004a7410`은 EXE의 `0x004c91f4`에 있는 `yfnt\hero.spr` 경로로 초상화 자원을 로드한다.
초상화 ID에서 프레임으로 가는 별도 표는
[브리핑 초상화 매핑](briefing-portraits.md)에 기록돼 있다.

## 640×480 좌표

좌표 원점은 좌상단이다.

| 숫자 슬롯 | X | Y | 오른쪽 | 아래쪽 | 크기 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 0 | 26 | 49 | 156 | 169 | 130×120 |
| 1 | 490 | 49 | 620 | 169 | 130×120 |
| 2 | 26 | 210 | 156 | 330 | 130×120 |
| 3 | 490 | 210 | 620 | 330 | 130×120 |

대사는 X 188, 최대 폭 278이며 계산된 텍스트 높이의 절반을 Y 190에서 빼 세로로 중앙 정렬한다.

기존 프로젝트의 `left`, `right`, `center`는 원본 숫자 `0`, `1`, `2`를 임의로 이름 붙인 값이었다.
특히 원본 슬롯 2는 중앙이 아니라 좌하단이다. 현재 시나리오 데이터는 의미 이름을 제거하고
`speechSlot: 0 | 1 | 2 | 3`을 그대로 보존한다.

## 실패 경로

`FUN_004a8410`은 signed 슬롯이 3보다 크면 `0x004a8458`로 빠진다. 알려진 슬롯 사각형을 만들지
않으므로 포팅 구현은 범위 밖 값을 임의 위치로 대체하지 않고 거부한다.

## 재현과 이식

- `tools/imjinrok/extract-speech-layout-evidence.mjs`가 EXE·SPR 해시, 14개 명령어 anchor,
  점프 테이블과 내장 자원 경로를 검증한다.
- `tools/imjinrok/speech-layout-evidence.test.mjs`가 네 슬롯, 대사 좌표, 자원 크기와 실패 입력을
  검사한다.
- `apps/game-client/src/originalSpeechLayout.ts`가 원본 캔버스를 화면에 균일 배율로 맞추고 남는
  공간을 여백으로 둔다.
- 브리핑과 미션 중 대화는 같은 변환 함수를 사용한다. 130×120 초상화를 정사각형으로 강제하지 않는다.
- 재생·게임 시작 버튼, 웹 글꼴 선택, 화면 클릭 입력은 포팅 전용이며 정적 확정 범위가 아니다.
