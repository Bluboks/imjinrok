# 조선 창병·내부 클래스 2 애니메이션 파일럿

기준일: 2026-07-26

## 판정 범위와 명칭

원본 엔티티의 내부 클래스 바이트 `2`가 원본 이름 `조선 창병`, 런타임 스프라이트 슬롯 `100`,
`char\swordk.spr`와 연결되는 식별 경로를 `정적 확정`했다. 프로젝트의 안정 ID `swordsman`은
호환성을 위해 유지하지만 표시 이름과 스프라이트 출처는 이 식별 결과에 맞췄다.

애니메이션 상태 1·2에서 방향과 phase가 프레임으로 변환되는 범위와 두 상태가 모두 이동 갱신
`0x00425b20`에서 선택되는 이동 비주얼임을 `정적 확정`했다. 상태 1 일반 분기는 프로젝트
`move`·`walk`에 이식했다. 상태 2는 환경·런타임 조건이 선택하는 별도 이동 비주얼임은 확정했지만
원본의 사람용 명칭은 아직 붙이지 않는다. idle, 공격 상태, 타격 시점과 전투 수치는 미확정이다.

## 상태 의미

| 상태 | 정적 확정 의미 | 선택 조건 | frame base |
| ---: | --- | --- | --- |
| 1 | 일반 이동 비주얼 | `BYTE [entity+0xba] != 1` | 0, 8, 16, 24, 32 |
| 2 | 별도 환경·런타임 이동 비주얼 | `BYTE [entity+0xba] == 1` | 88, 96, 104, 112, 120 |

상태 2 선택자는 flags `0x04000000`, 이동 보간값 `+0x4f2`, 필드 `+0x4c2`, 함수
`0x00442770`, 현재 맵 셀 값과 플레이어별 값을 함께 검사한다. 이 전체 제어 흐름은 이동 함수 안에
있으므로 두 상태를 공격이나 idle로 해석할 수 없다. 다만 이 조건 묶음이 원본 UI·설명에서
물·늪·지형 등 무엇으로 불렸는지는 아직 확정하지 않는다.

## 방향과 프레임

phase는 `WORD +0x1b2`, 방향은 `WORD +0x1e6`에서 읽는다. 두 상태 모두 phase 범위는 0~7이다.
상태 1의 아래 표는 `(DWORD entity+0x74 & 0x80000008) == 0`인 일반 분기에 적용한다. 클래스 2의
초기 flags `0x04080805`와 이 마스크의 교집합은 0이므로 생성 직후에는 일반 분기를 사용한다.
상태 2에는 이 선행 분기가 없다.

| 방향값 | 이동 ΔX,ΔY | 상태 1 프레임 | 상태 1 미러 | 상태 2 프레임 | 상태 2 미러 |
| ---: | --- | --- | --- | --- | --- |
| `0x01` | 0,+1 | 0~7 | 아니오 | 88~95 | 아니오 |
| `0x04` | -1,0 | 16~23 | 아니오 | 104~111 | 아니오 |
| `0x05` | -1,+1 | 8~15 | 아니오 | 96~103 | 아니오 |
| `0x10` | 0,-1 | 16~23 | 예 | 104~111 | 예 |
| `0x14` | -1,-1 | 24~31 | 아니오 | 112~119 | 아니오 |
| `0x40` | +1,0 | 0~7 | 예 | 88~95 | 예 |

현재 클라이언트의 격자 방향 계산은 `+X=동`, `+Y=남`이다. 따라서 위 ΔX·ΔY를 프로젝트 `Facing`에
직접 대응해 상태 1 일반 이동을 다음처럼 이식했다.

## 상태 1 특수 방향 분기

마스크가 설정되면 상태 1은 `WORD +0x1e8`을 읽는다. 일반 범위의 방향값 8개와 특수 값
1000~1007의 분기 목적지·frame base 필드·mirror 쓰기까지 복원했다.

그러나 클래스 2의 상태 1 초기화 함수는 `+0xa8`~`+0xb0`의 다섯 base만 설정한다. 특수 분기는
추가로 `+0xb2`, `+0xb4`, `+0xb6`, `+0xb8`을 읽는다. 따라서 분기 구조 자체는 확인했지만 클래스
2에서 전체 특수 분기를 안전하게 재현할 근거는 없다. 런타임 중 `+0x74`가 바뀌어 이 분기에 진입할
가능성도 아직 배제하지 않았으므로 추출기는 마스크가 설정된 입력을 계속 거부한다.

## 재현과 남은 경계

- `tools/imjinrok/extract-unit-animation-pilot.mjs`가 입력 해시, 자원 포인터, 클래스·상태·방향 점프
  테이블, 이동 함수의 상태 쓰기, 타입 flags 복사, 특수 분기와 렌더 경로를 검증한다.
- `tools/imjinrok/unit-animation-pilot.test.mjs`가 두 상태의 8방향과 phase 양 끝, 기본 분기와
  잘못된 입력, 특수 분기 격리와 정적 분석 산출물의 원본 해시를 검사한다.
- 원본 gameplay 이름과 `swordk.spr` 출처는 확정되어 프로젝트 표시 이름을 `조선 창병`으로
  바로잡았다. 안정 ID `swordsman`은 저장·명령 호환성을 위한 프로젝트 이름일 뿐 원본 명칭이 아니다.
- 상태 1 일반 이동의 방향·미러·frame 0~39는 현재 테마의 `move`·`walk`에 이식했다.
- 상태 2 통합, 상태 1 특수 분기의 클래스 2 base 초기화, idle, 공격 상태와 나머지 프레임은
  미확정이다.
- 현재 `attack` frame 48~87은 기존 임시 연결이며 이 파일럿의 원본 기반 범위가 아니다.
