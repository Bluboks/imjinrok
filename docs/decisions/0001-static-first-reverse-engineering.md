# ADR-0001: 정적 분석 우선 역공학

- 상태: 채택
- 결정일: 2026-07-26

## 배경

기존 작업은 Codex가 MCP를 통해 Windows VM의 원본 게임을 조작하고, x32dbg와 메모리 캡처로 빠르게
변하는 게임 상태를 추적하는 데 많은 시간을 사용했다.

게임 입력 한 번 뒤에 여러 상태가 빠르게 진행되기 때문에 자동화가 원하는 시점에 도달하기 어려웠다.
타이밍 실패와 `no-hit`이 반복되었고, 제한적인 캡처가 전체 메커니즘 증거처럼 확대될 위험도 생겼다.

원본 실행 파일은 고정 주소 기반의 32비트 x86 PE이며 패킹이나 본격적인 난독화 흔적이 없다. 코드,
문자열, 전역 데이터와 별도 원본 자원이 남아 있으므로 정적 분석을 주 경로로 사용할 수 있다.

## 결정

- 원본 바이너리와 데이터의 정적 분석을 발견과 명세의 기본 방법으로 사용한다.
- 제어 흐름, 데이터 흐름, 구조체와 테이블을 복원한 뒤 독립 테스트로 재현한다.
- 검증된 메커니즘만 현재 구현에 이식한다.
- 동적 분석은 정적으로 남은 좁은 질문을 확인하는 예외 절차로 제한한다.
- 화면 유사성은 이상 탐지와 최종 확인에만 사용한다.

## 결과

- Ghidra 기반 재현 가능한 정적 분석 파이프라인이 필요하다.
- 기존 VM 추적 문서는 과거 기록으로 보관한다.
- 기존 구현은 원작 일치가 검증되기 전까지 프로토타입으로 취급한다.
- 문서와 테스트는 주소·수식·상태 변화와 원본 해시를 추적해야 한다.
- 분석 속도가 느려질 수 있지만, 잘못된 추정을 구현에 누적하는 위험을 줄인다.

## 동적 분석 예외

정적 분석으로 두 가지 이상의 해석이 남고, 그 차이가 실제 이식 동작에 영향을 주며, 격리 실행으로도
답을 얻을 수 없을 때만 동적 검증을 제안한다. 구체적인 절차는
[동적 검증 지침](../agent-guides/dynamic-validation.md)을 따른다.
