# 2026-07-26 이전 문서 보관소

이 디렉터리는 정적 분석 우선 체계로 전환하기 전의 문서와 지침을 보존한다.

## 주의

- 이 디렉터리의 문서는 현행 작업 절차가 아니다.
- `verified`, `proof`, `parity`, `achieved` 같은 과거 표기를 현재 증거 등급으로 해석하지 않는다.
- 주소와 상수는 유용한 탐색 단서지만 원본 실행 파일 해시를 확인하고 다시 분석해야 한다.
- VM 마커가 가리키는 원시 JSON·메모리 덤프는 이 저장소에 함께 보존되어 있지 않다.
- 현행 문서는 [문서 안내](../../README.md)에서 시작한다.

- `project-readme.md`: 이전 프로젝트 README
